# Freedom Link — Secure Messenger

Защищенный мессенджер с локальным хранением данных и сквозным XOR-шифрованием.

## 🛠 Системные требования
- **Python:** версия 3.8 или выше.
- **Зависимости:** `customtkinter`, `websockets`.
- **Установка:** 
  ```bash
  pip install -r requirements.txt
  ```

## 🚀 Порядок запуска
**Важно:** Для работы мессенджера первым делом должен быть запущен центральный узел (сервер).

1. **Запуск сервера:**
   ```bash
   python server.py
   ```
   Сервер должен оставаться запущенным на протяжении всего сеанса связи.

2. **Запуск клиентов:**
   ```bash
   python gui.py
   ```
   Вы можете запустить несколько экземпляров `gui.py`, чтобы протестировать переписку между разными пользователями.

## 👤 Первый запуск и Идентификация
При первом запуске приложение предложит вам ввести ваше имя (User ID). 
- Это имя используется сервером для маршрутизации сообщений.
- **Сохранение:** Ваше имя сохраняется в файл `user_id.txt`, чтобы вам не приходилось вводить его при каждом перезапуске.
- **Смена имени:** Чтобы изменить свой ID, просто удалите файл `user_id.txt` из папки проекта и перезапустите приложение.

## 📖 Руководство по эксплуатации

### Выбор контакта
В левой панели (Sidebar) отображается динамический список всех пользователей, которые в данный момент авторизованы на сервере. Чтобы начать общение, просто нажмите на имя нужного собеседника. Окно чата автоматически переключится на него и загрузит историю переписки из локальной базы данных.

### Индикаторы статуса
Цвет кнопки контакта в сайдбаре отражает его текущее состояние в сети:
- 🟢 **Зеленый:** Пользователь в сети (Online) и доступен для общения.
- 🔴 **Красный:** Пользователь вышел из сети (Offline).

### Отправка сообщений
1. Выберите собеседника.
2. Введите текст в поле ввода в нижней части экрана.
3. Для отправки нажмите кнопку **«Отправить»** или используйте клавишу **Enter** для быстрого обмена сообщениями.

### Управление историей
Все сообщения сохраняются локально в файле `chat_history.db`. Для полной очистки переписки с текущим собеседником воспользуйтесь кнопкой **«Очистить чат»**.

## 🔒 Безопасность и Приватность
Freedom Link использует принцип минимального доверия к узлу связи:
- **XOR-шифрование:** Все сообщения шифруются на стороне отправителя и расшифровываются только на стороне получателя.
- **Приватность:** Сервер-маршрутизатор видит только зашифрованный трафик («шум») и не имеет доступа к содержимому ваших переписок.
- **Локальность:** История сообщений хранится исключительно на вашем устройстве, а не на сервере.
